# 李轩然｜企业传播与品牌内容作品集

静态站点，网站根目录为本文件所在目录；部署到 GitHub Pages 等静态托管平台时，直接上传本目录内容即可。

## 网站地图

- `index.html`：首页（3 个精选案例、3 个更多项目）
- `case-lingdong.html`：凌动科技企业品牌内容升级
- `case-guowei-corporate.html`：国微电子企业内容传播体系
- `case-cangzhao-engineering.html`：苍昭高速工程项目传播
- `work-manufacturing-technology.html`：凌动科技制造与技术传播
- `case-employee-storytelling.html`：凌动百工志人物故事
- `work-video-visual.html`：视频与视觉传播合集
- `work-annual.html`：年度整合传播（由案例页与视频视觉页进入）

网页使用相对路径引用 `assets/`，请保留本目录中全部文件与相对目录结构，不要只上传 HTML。网页视频采用 H.264 MP4，点击后播放。
